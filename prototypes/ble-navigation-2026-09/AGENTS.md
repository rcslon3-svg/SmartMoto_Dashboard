# Продолжение этого стенда

Перед работой прочитать `README.md`, `STATUS.md`, а для Android BLE — сохранённые `source/cyd-companion-v2/HANDOFF.md`, `ARCHITECTURE.md` и `VALIDATION.md`.

Пользователь запретил ADB. Не использовать ADB. Не считать локальную сборку доказательством поведения Xiaomi, CDM или дисплея. Отличать завершение процесса от Force Stop. Для сборки и загрузки применять только уже проверенные команды из `BUILD.md` с соответствующим окружением. Если проверенная команда не сработала, выяснить причину до смены способа. Не повторять просьбы перезагрузить телефон без конкретной диагностической цели.

`source/` — сохранённый снимок рабочих папок, не автоматическая синхронизация. Не редактировать копии и исходные рабочие папки врозь без последующего осознанного импорта и проверки diff. Не добавлять в публичный репозиторий журналы телефона, серверные `data/`, `local.properties`, `.env`, резервные образы flash или кэши сборки.
