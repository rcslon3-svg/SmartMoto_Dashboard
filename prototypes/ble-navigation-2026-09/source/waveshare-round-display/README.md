# Waveshare ESP32-S3-LCD-1.47B + внешний GC9A01

Проект именно для **ESP32-S3-LCD-1.47B** (USB-C), внешний круглый дисплей 1,28″ 240×240. Преобразователь уровней не нужен. На встроенном прямоугольном экране подсветка выключается через GPIO46; весь интерфейс выводится на круглый экран.

## Подключение

Монтаж при отключённых USB и аккумуляторе. Названия GPIO — маркировка IO на плате, не порядковые номера контактов.

| GC9A01 | Waveshare 1.47B |
| --- | --- |
| VCC | 3V3, **не VBUS/5V** |
| GND | GND |
| SCL / SCK | IO4 |
| SDA / DIN | IO5 |
| CS | IO6 |
| DC | IO7 |
| RST / RES | IO8 |

Здесь SDA/SCL — SPI, не I²C. Для первого запуска питание платы через USB-C, аккумулятор не требуется. Провода короткие, желательно до 10 см. На изображении дисплея семь контактов; дополнительного BL нет.

GPIO4–8 свободны согласно [схеме версии B](https://files.waveshare.com/wiki/ESP32-S3-LCD-1.47B/ESP32-S3-LCD-1.47B_schematic_diagram.pdf). Встроенный LCD использует GPIO39/40/41/42/45/46, поэтому не конфликтует с внешним. [Документация платы](https://www.waveshare.com/wiki/ESP32-S3-LCD-1.47B).

## Что показывает

Постоянно отображаются ODOMETER и TRIP. Начальные значения 000000 km и 888.0 km. Каждую секунду Trip увеличивается на 0,1 км, при переходе через целый километр одометр увеличивается на 1 км: 888.9 / 000000 → 889.0 / 000001. Это демонстрация без датчика пробега и записи EEPROM; после перезапуска значения возвращаются к начальным. Расчёт в целых сотнях метров, без float. Латинские шрифты. Тёмный фон с синим свечением у нижнего края, тонкая рамка, крупные цифры.

Статический фон и подписи рисуются в RAM (115200 байт) и передаются дисплею при запуске. Затем обновляются только окна изменившихся цифр: старая цифра уезжает вверх, новая появляется снизу. Разряд сотен метров непрерывно движется к следующей цифре за kTickIntervalMs = 1000 мс, без паузы между переходами. Остальные изменившиеся разряды прокручиваются за kAnimationMs = 200 мс при переносе. Шаг кадров kFrameMs = 16 мс. Окна обрезают цифры по вертикали; неизменные цифры и десятичная точка неподвижны. Это не гарантирует отсутствие tearing: отдельный сигнал синхронизации кадров не используется. Шаг счётчика 1000 мс, millis() учитывает переполнение. При задержке цикла учитываются все прошедшие полные секунды.

## Сборка и загрузка

Открыть эту папку в PlatformIO. `pio run` — сборка. Для загрузки выбрать фактический порт именно Waveshare:

```powershell
pio run -e waveshare_s3_147b -t upload --upload-port COMx
```

Заменить COMx на порт платы. Загрузка заменит её текущую прошивку. Не использовать порт старой ESP32/CYD или Nano. Если автоматический вход в загрузчик не сработал: удерживая BOOT, нажать и отпустить RESET, затем отпустить BOOT; повторно проверить порт и загрузить. После ручного входа в загрузчик может потребоваться RESET для запуска.

Плата настроена на 16 МБ Flash, PSRAM для демо не используется. USB CDC включён, Serial Monitor 115200. Программа не ждёт подключения монитора. Строки `page=ODO odo=... trip=... drum_period_ms=1000 tick_ms=... heap=...` подтверждают выполнение кода, но не изображение на дисплее.

Настройки в `src/main.cpp`: `kRotation` 0–3 (поворот), `kTickIntervalMs`, начальные значения `kInitialOdometerKm`, `kInitialTripTenths` (сотни метров). SPI 20 МГц; при нестабильном изображении уменьшить `kSpiHz` до 10000000 или 4000000 и проверить проводку. При пустом экране проверять питание, RST/DC/CS и соответствие GPIO. Чёрный встроенный экран после загрузки ожидаем.

Этот проект не управляет мотором и не изменяет проекты Nano, CYD или Android BLE. ADB не используется.

## Навигация по BLE, 23 сентября 2026

Новая прошивка рекламирует GATT service UUID `a4aa19e0-c1ec-4f71-96fe-b5750060cc01` под именем `MotoNav-Round`. Android NavProbe 1.1.0 передаёт две дистанции и маску значка 48×48. Когда навигационные данные получены, экран чередует страницу одометра и навигации каждую секунду; без данных остаётся страница одометра. На странице навигации показаны стрелка, дистанция до манёвра и дистанция до финиша. После отключения BLE навигация очищается. Строки `nav_rx` и `nav_screen` в Serial различают приём законченного сообщения и выполнение отрисовки. GATT не требует спаривания и не имеет аутентификации; это стендовая локальная реализация.

Сборка выполнена прежней проверенной командой `pio run -d waveshare-round-display -e waveshare_s3_147b` (успешно). Прошивка загружена прежней проверенной командой `pio run -d waveshare-round-display -e waveshare_s3_147b -t upload --upload-port COM5` на плату с MAC `A4:CB:8F:DA:D3:B0`; хеши записи проверены esptool. Serial после прошивки подтвердил продолжающийся цикл одометра, heap 143164 байта. Android ↔ BLE ↔ дисплей с телефоном пока не проверен; пользователь должен установить новый APK и подтвердить картинку на дисплее.

Копия прошивки: `releases/motonav-round-1.1.0.bin`, SHA256 `E91B4CDECD37515BE618D39FDC98E89ABB541DE0691ADFEFE11CD51D74DAC2AE`.
