# Google Maps: данные уведомления

Отдельный APK `demo.cyd.navprobe` для проверки на телефоне. Он не подключается к ESP32 и не изменяет два существующих APK. У APK нет разрешений INTERNET или BLUETOOTH. Данные живут только в памяти процесса и показываются на экране. Android требует вручную выдать доступ к уведомлениям; системное предупреждение относится ко всем уведомлениям, но код немедленно отбрасывает пакеты, отличные от `com.google.android.apps.maps`.

## Что изучено

- [CatDrive NavigationListener](https://github.com/maisonsmd/esp32-google-maps/blob/main/android-app/app/src/main/java/com/maisonsmd/catdrive/service/NavigationListener.kt): `NotificationListenerService`, чтение активных уведомлений при подключении, фильтр Google Maps, обновления и удаление. В исходнике фильтр дополнительно требует `id == 1`: это значение не является Android-контрактом, поэтому здесь фильтра по ID нет.
- [CatDrive GMapsNotification](https://github.com/maisonsmd/esp32-google-maps/blob/main/android-app/app/src/main/java/com/maisonsmd/catdrive/lib/GMapsNotification.kt): восстановление/разворачивание `RemoteViews`, чтение `TextView` и `right_icon`. Такое чтение зависит от внутренней разметки уведомления Google Maps. В приложении результат и ошибка показываются отдельно.
- [CarPlayBLE NotificationService](https://github.com/appleshaman/CarPlayBLE/blob/main/CarPlayAndroid/app/src/main/java/com/example/carplay_android/services/NotificationService.java): `EXTRA_TITLE`, `EXTRA_SUB_TEXT`, другие текстовые поля и `largeIcon`; формат строк и сопоставление изображения с образцами проекта могут зависеть от версии Maps и языка. Здесь показаны исходные значения и изображение без объявления распознанного манёвра.
- [Drive Assistant](https://github.com/DEMP1993/Drive-assistant-android-app): фильтрация Maps, чтение `title`/`text`/`subText`/`bigText`, отдельный парсер и режим отладки полей. Для этого исследования используются технические приёмы, код проекта не скопирован. На странице проекта указана лицензия PolyForm Noncommercial.

## Как проверить без ADB

1. Установить `releases/cyd-navprobe-1.1.0.apk` вручную на телефон.
2. Открыть приложение, нажать «Открыть доступ к уведомлениям» и разрешить доступ для «Чтение уведомлений Google Maps» в системных настройках.
3. В Google Maps включить уведомления и запустить реальную навигацию. Вернуться в приложение. Если данных нет, нажать «Прочитать активные уведомления».
4. Записать или сфотографировать экран при начале маршрута, приближении к манёвру, после манёвра и после завершения. Не делать вывод о доступности данных из одного снимка.
5. Для передачи на Waveshare с прошивкой из `waveshare-round-display` включить Bluetooth и нажать «Подключить круглый дисплей по BLE». Разрешить «Устройства поблизости». Чтобы завершить передачу, нажать «Отключить BLE».

`Получено уведомление` означает только вызов Android с пакетом Google Maps. `ongoing`, канал и ID показаны, чтобы отличить навигационное уведомление от других уведомлений Maps. `RemoteViews` может оказаться пустым или недоступным; ошибка чтения выводится на экран. Значок показывается как полученное изображение, а не как проверенный тип манёвра. Поведение новой версии на телефоне ещё не проверено.

## Передача на круглый дисплей, версия 1.1.0

Телефон ищет только GATT service UUID `a4aa19e0-c1ec-4f71-96fe-b5750060cc01` устройства `MotoNav-Round`. Явно запущенная пользователем служба типа `connectedDevice` поддерживает соединение при открытых Google Maps. Из `TITLE` и `SUB_TEXT` извлекаются первая дистанция до манёвра и дистанция до финиша; для наблюдавшегося русского формата `140 м`, `2,8 км` передаются `140m`, `2.8km`. Это зависимый от локали разбор, а не официальный API Google Maps. Белый значок из `largeIcon` (или из `RemoteViews` при его отсутствии) уменьшается до 48×48 и превращается в монохромную маску. Текст улицы пока не передаётся: текущий шрифт прошивки не содержит тайских символов. При отсутствии обеих дистанций плата получает команду очистки навигации.

Сообщения укладываются в исходный ATT payload 20 байт: `N` с последовательностью, длинами и двумя ASCII-дистанциями; 18 кадров `I` по 16 байт изображения; `E` для завершения; `C` для очистки. Плата показывает результат только после всех кадров текущей последовательности. На телефоне счётчик «Завершено записей по GATT» означает успешный ответ BLE стека на последний кадр, но не подтверждает изображение на дисплее. Соединение и экран на телефоне с версией 1.1.0 ещё не проверены.

## Наблюдение на Xiaomi, 23 сентября 2026

Снимки экрана работающего приложения подтвердили получение навигационного уведомления Google Maps: ID 1, канал `1_foreground_1`, `ongoing=true`, текстовых полей и белой стрелки в `largeIcon` и `right_icon` восстановленного `RemoteViews`. На белом фоне стрелка почти не читалась, поэтому версия 1.0.1 добавляет тёмную подложку в экранном просмотре без изменения самих bitmap. Новая версия ещё не проверена на телефоне.

В PowerShell из `cyd-companion-v2/android`:

```powershell
$env:JAVA_HOME='C:\Program Files\Android\Android Studio\jbr'
& 'C:\Users\LENOVO\.gradle\wrapper\dists\gradle-9.2.1-bin\2t0n5ozlw9xmuyvbp7dnzaxug\gradle-9.2.1\bin\gradle.bat' :navprobe:assembleDebug :navprobe:lintDebug
```

Этот вызов 23 сентября завершился `BUILD SUCCESSFUL`. В текущем ограниченном окружении запуск `gradlew.bat` пытался повторно скачать Gradle, а запуск установленного Gradle с `--offline` не нашёл Android Gradle Plugin 9.0.1; они не являются проверенным способом здесь. Для загрузки отсутствующего плагина потребовался сетевой доступ. Выходной файл: `android/navprobe/build/outputs/apk/debug/navprobe-debug.apk`.
