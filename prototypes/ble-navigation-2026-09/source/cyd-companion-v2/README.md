# CYD — мост и отдельный диагност

Два новых APK для Android 13+. Старое приложение и прошивка ESP32 сохранены. ADB не нужен и не использовался.

1. Установить **оба** APK с http://192.168.1.101:8787/diagnostics . В старом приложении выключить мост и автозапуск.
2. Открыть **CYD Диагност**, сохранить адрес сервера. Это его первый обязательный пользовательский запуск.
3. Открыть **CYD Companion 2**: сохранить адрес, разрешить Bluetooth/уведомления, выбрать плату через системное окно, включить наблюдение и связь. Уже существующая системная Bluetooth-пара не заменяет CDM-привязку нового пакета.
4. Открыть **CYD Диагност**. Он читает свой журнал и PackageManager, не запуская мост. Кнопка «Завершить процесс моста» выполняет проверяемый handshake. Успешное завершение фиксируется только событием BRIDGE_PROCESS_DIED. Дальнейшие события моста приходят сами.

Для проверки именно нового появления платы физически выключить её перед завершением процесса, дождаться **подтверждения смерти процесса в диагносте**, затем включить плату. Не нажимать кнопки состояния/архива и не открывать мост. Отсутствие восстановления фиксируется как отсутствие подтверждения; бессрочно ждать «успеха» приложение не требует. Для другого сценария плату можно оставить включённой, но это уже проверка восстановления при непрерывно присутствующей плате.

Не использовать системную «Принудительную остановку» как замену завершения процесса. Это отдельный сценарий stopped-пакета. Новые APK на физическом телефоне ещё не проверены; локальная сборка не заменяет эту проверку.

Полная архитектура, источники и ограничения: [ARCHITECTURE.md](ARCHITECTURE.md).

Локальные проверки: `./test-local.ps1`. Сборка обоих APK: из android выполнить `./build-local.bat --no-daemon --gradle-user-home ../../ble-internet-demo/android/.gradle-home assembleDebug lintDebug`.
