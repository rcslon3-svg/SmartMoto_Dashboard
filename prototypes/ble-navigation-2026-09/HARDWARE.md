# Платы и подключение

## CYD: отдельный BLE-мост

Плата стенда — ESP32-2432S028R / Cheap Yellow Display, ILI9341 320×240; прошивка в `source/ble-internet-demo/firmware`. На исходной станции плата была подтверждена на COM4, BLE MAC `68:09:47:58:FA:E6`. Перед загрузкой обязательно заново идентифицировать устройство: COM-номер может измениться. Android-мост связывается с этой платой через BLE, получает события и обменивается данными с локальным HTTP-сервером.

## Waveshare: круглая навигация

Фактически использовалась **Waveshare ESP32-S3-LCD-1.47B**, внешний круглый **GC9A01 240×240**. Это не Arduino Nano. Предыдущий код Nano хранится отдельно как прототип.

| GC9A01 | Waveshare 1.47B |
| --- | --- |
| VCC | 3V3 |
| GND | GND |
| SCL / SCK | IO4 |
| SDA / DIN | IO5 |
| CS | IO6 |
| DC | IO7 |
| RST / RES | IO8 |

`SDA`/`SCL` у этого дисплея — линии **SPI**, не I²C. Питание и сигналы рассчитаны на 3,3 В; подключение к 5 В Nano без преобразователя уровней не использовалось. Встроенный прямоугольный экран Waveshare программно погашен, внешний круглый остаётся рабочим. [Схема Waveshare 1.47B](https://files.waveshare.com/wiki/ESP32-S3-LCD-1.47B/ESP32-S3-LCD-1.47B_schematic_diagram.pdf).

Проверенная на исходной станции плата Waveshare: COM5, MAC `A4:CB:8F:DA:D3:B0`. Порты не взаимозаменяемы: загрузка прошивки круглого экрана на CYD или наоборот сотрёт текущую программу не той платы.

## Телефон

Стенд использовал Xiaomi 23117RA68G с Android 13. Мост `demo.cyd.companion` и NavProbe `demo.cyd.navprobe` — разные APK. Системную привязку CompanionDeviceManager делает **мост с CYD**; NavProbe вручную подключается к Waveshare по собственному BLE GATT-сервису. Выдача NavProbe доступа к уведомлениям требует системного согласия пользователя. Доступ технически охватывает уведомления других приложений, хотя код обрабатывает только пакет Google Maps.
